# ROS2 Mobile Robot Navigation and Closed-loop Evaluation System

## Overview

A ROS2-based mobile robot autonomous navigation framework.

This project aims to build a modular navigation system including:
- ROS2 communication architecture
- Motion planning
- Path tracking control
- Simulation experiments
- Closed-loop performance evaluation

## Environment

- Ubuntu 24.04 LTS
- ROS2 Jazzy
- C++
- CMake
- colcon
